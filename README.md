# PIZZA LAB 🍕

Демонстрационный storefront доставки пиццы для российского рынка. Интерфейс на русском языке, цены в рублях, адаптивная вёрстка и рендеринг на стороне сервера.

## Технологии

- Next.js 16 — App Router
- React 19 + TypeScript
- Tailwind CSS 4
- Zustand — состояние корзины (следующий этап)
- React Hook Form + Zod — формы (следующий этап)
- Lucide React — иконки
- pnpm

## Запуск

Требуется Node.js 20.9+ и pnpm 10+.

```bash
pnpm install
pnpm dev
```

Откройте http://localhost:3000.

## Скрипты

| Команда | Назначение |
| --- | --- |
| `pnpm dev` | Локальная разработка |
| `pnpm build` | Production-сборка |
| `pnpm start` | Запуск production-сервера |
| `pnpm lint` | ESLint |
| `pnpm typecheck` | Проверка TypeScript |

## Структура

- `src/app` — маршруты, layout, metadata и глобальные стили
- `src/entities` — модели и данные товаров
- `src/features` — пользовательские сценарии
- `src/widgets` — крупные секции страниц
- `src/shared` — общие компоненты и конфигурация

## Статус

Первый этап: главная страница, hero-блок, меню, промо-секция и футер. Каталог использует демонстрационные данные и изображения Unsplash. Реальная отправка заказов, оплата и интеграция с доставкой не подключены.
