# PIZZA LAB 🍕

Демонстрационный сайт доставки пиццы для российского рынка. Интерфейс на русском языке, цены в рублях, адаптивная вёрстка и серверный рендеринг на Next.js. Проект не принимает реальные заказы и платежи.

Изображения хранятся локально в `public/images`: во время просмотра сайт не обращается к Unsplash, Google Fonts или сторонним CDN за фотографиями и шрифтами.

## Технологии

- Next.js 16 — App Router и серверный рендеринг
- React 19 + TypeScript
- Tailwind CSS 4
- Zustand — состояние корзины и сохранение её содержимого
- React Hook Form + Zod — форма и валидация оформления заказа
- Lucide React — иконки
- Vitest — unit-тесты
- pnpm — управление зависимостями

## Запуск

Требуется Node.js 20.9+ и pnpm 10+.

```bash
pnpm install
pnpm dev
```

Откройте http://localhost:3000.

| Команда | Назначение |

## Структура

- `src/app` — маршруты, layout, metadata и глобальные стили
- `src/entities` — модели и данные товаров
- `src/features` — пользовательские сценарии и бизнес-логика
- `src/widgets` — крупные секции страниц
- `src/shared` — общие компоненты и конфигурация

## Функциональность

- Каталог пицц с выбором размера и расчётом цены
- Корзина с изменением количества, удалением и сохранением содержимого
- Оформление демонстрационного заказа с проверкой контактных данных
- Выбор доставки или самовывоза и расчёт стоимости доставки
- Модальное окно с условиями заказа и клавиатурной навигацией
- Интерактивное табло режима работы

## Демонстрационный режим

PIZZA LAB — портфолио-концепт. Форма оформления не отправляет персональные данные на сервер, заказ не поступает в ресторан, а онлайн-оплата не проводится. Цены, режим работы, сроки и условия доставки приведены исключительно для демонстрации интерфейса и требуют настройки под конкретный ресторан.
