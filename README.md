# PIZZA LAB

**Концепт сайта доставки пиццы** на React, TypeScript и Vite. Небольшой коммерческий демо-проект с адаптивным интерфейсом, меню, корзиной и оформлением заказа.

<https://artkoro94.github.io/pizza-lab/>

> Это демонстрационный проект. Реальные заказы и платежи не принимаются, персональные данные не отправляются и не сохраняются.

## Возможности

- Адаптивная главная страница с меню и промо-блоком.
- Каталог пиццы с выбором размера и автоматическим пересчётом цены.
- Корзина с изменением количества, удалением позиций и сохранением состояния между перезагрузками.
- Расчёт стоимости заказа и условий доставки.
- Форма оформления заказа с валидацией.
- Выбор доставки или самовывоза.
- Информация о режиме работы и условиях доставки.
- Небольшие анимации интерфейса с поддержкой настройки reduced motion.

## Локальный запуск

Требуются Node.js 20.9+ и pnpm 10+.

```bash
pnpm install
pnpm dev
```

Vite выведет локальный адрес в терминал.

## Проверки и production-сборка

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm preview
```

Production-сборка создаётся в директории `dist`.

## Публикация

Проект размещён на GitHub Pages. GitHub Actions автоматически собирает и публикует сайт после push в `main`. Для корректной работы на GitHub Pages настроен базовый путь `/pizza-lab/` и обработка вложенного маршрута оформления заказа.

## Структура проекта

Код организован по функциональным слоям:

- `src/app` — приложение, маршруты и глобальные стили.
- `src/entities` — модели и данные предметной области.
- `src/features` — независимые пользовательские сценарии: корзина, оформление заказа, доставка.
- `src/widgets` — крупные блоки страниц: шапка, главный экран, меню, промо и подвал.
- `src/shared` — общие компоненты и конфигурация.

## Примечание

Ассортимент, цены, адрес и условия доставки используются только для демонстрации интерфейса и пользовательских сценариев.
