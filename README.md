# PIZZA LAB 🍕

Демонстрационный сайт доставки пиццы для российского рынка. Современный адаптивный интерфейс на русском языке, цены в рублях и рабочий пользовательский сценарий от выбора пиццы до подтверждения демо-заказа.

> **Важно:** это портфолио-концепт. Реальные заказы и платежи не принимаются, данные формы не отправляются на сервер.

## Возможности

- Каталог пицц с выбором размера и динамическим расчётом цены.
- Корзина: изменение количества, удаление позиций и сохранение содержимого между посещениями.
- Оформление заказа с валидацией контактных данных.
- Доставка и самовывоз, автоматический расчёт стоимости доставки.
- Информационное окно с условиями заказа.
- Адаптивная главная страница и интерактивные элементы.

## Технологии

- Next.js 16 (App Router), React 19, TypeScript
- Tailwind CSS 4
- Zustand
- React Hook Form + Zod
- Lucide React
- Vitest
- pnpm

## Локальный запуск

Требуются Node.js 20.9+ и pnpm 10+.

```bash
pnpm install
pnpm dev
```

Откройте http://localhost:3000.

## Переменные окружения

Скопируйте `.env.example` в `.env.local`.

| Переменная | Назначение |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Публичный URL сайта без завершающего слеша |

Для локальной разработки используется `http://localhost:3000`. На Vercel URL автоматически определяется через `VERCEL_URL`, но для production рекомендуется явно задать `NEXT_PUBLIC_SITE_URL` с основным доменом.

## SEO и производительность

- Русский язык документа и метаданные для поисковых систем.
- Canonical URL, Open Graph и Twitter metadata.
- Автоматические `/robots.txt` и `/sitemap.xml`.
- Страница оформления исключена из индексации.
- Изображения и графика хранятся локально в репозитории; внешние image CDN и web fonts не требуются.
- Главное изображение Hero загружается с приоритетом, остальные изображения проходят через оптимизацию Next.js.

## Структура проекта

- `src/app` — маршруты, layout, metadata и глобальные стили
- `src/entities` — модели и данные товаров
- `src/features` — пользовательские сценарии и бизнес-логика
- `src/widgets` — крупные секции страниц
- `src/shared` — общие компоненты и конфигурация

## Демонстрационный режим

Форма оформления имитирует подтверждение заказа, но не передаёт персональные данные, не создаёт заказ в ресторане и не выполняет оплату. Ассортимент, цены, телефон, режим работы и условия доставки — демонстрационные данные, которые нужно заменить при адаптации под реальный бизнес.
